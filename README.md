## Projects

### [Spirit Cube](https://github.com/Lohannz/spirit-cube)

My contributions include:

- Free camera system.
- Audio integration.
- Level loading and scene integration.

### [PathoShift](https://github.com/Lohannz/pathoshift)
**Python · OpenCV · NumPy · scikit-learn**

A computer vision and machine learning project focused on breast histopathology image classification.

The project includes image processing, feature extraction, classification experiments, and evaluation. I also worked on case-level data splitting and leakage checks to avoid unreliable evaluation results.

### [Sketch Proportions](https://github.com/Lohannz/sketch-analyzer)
**Python · OpenCV · Computer Vision**

A project exploring computer vision techniques for analyzing character drawings.

The goal is to investigate the measurement of drawing proportions and projective consistency through image processing.
