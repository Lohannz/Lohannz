# Lohan Vieira

Computer Science student at UFRRJ (Rio de Janeiro). I build games and
computer-vision tools, and I care about the boring parts: tests, deterministic
simulation and documented decisions.

### What I'm working on

**Hollowblox** — a 2D side-scrolling survival game for Roblox, written in Luau.
Enemies move on the beat of the music and the simulation runs on a deterministic
`BeatClock`. Pure modules, 94 automated tests and a Rojo build.
→ [repository](https://github.com/Lohannz/hollowblox)

**Spirit Cube** — a 3D platformer in Godot 4 where light melts ice and wind
changes gravity. Team project for the Computer Graphics course; I built the
menus, loading screen, free camera and audio integration.
→ [repository](https://github.com/Lohannz/spirit-cube)

**PathoShift** — an OpenCV + scikit-learn pipeline for breast histopathology
images. Case-level split with leakage assertion, balanced accuracy against a
majority baseline, and an honest negative result.
→ [repository](https://github.com/Lohannz/pathoshift)

**Sketch Proportions** — my undergraduate thesis: measuring proportions and
projective consistency in character drawings with OpenCV.
→ [repository](https://github.com/Lohannz/sketch-analyzer)
